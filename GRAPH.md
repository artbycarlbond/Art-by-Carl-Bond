## What This File Is

`GRAPH.md` is now the hub for the archive's text maps.

Open [GUIDE.html](GUIDE.html) for the browser welcome mat and short guided tour.

It is not the whole graph.
It is the first doorway into smaller graph sections.

Use it when you need to know which relationship map to open before choosing one active file.

Stop when one graph section,
one active file,
one source shelf,
one verification need,
or one return outside the archive is clear.

## Core Paths

New reader:

Choose one useful file through [ROUTES.md](ROUTES.md),
or begin directly with [Card 1](practice/cards.md#card-1-ten-minute-ai-answer-or-claim-audit).
Use [README.md](README.md) and [FIELD_STANDARD.md](FIELD_STANDARD.md) when background helps the task.
The next action can come before a tour of the archive.

Relationship map:

```text
README.md
  -> GRAPH.md
  -> one graph section
  -> one active file
  -> one return outside the archive
```

Source pressure to workbench use:

```text
source-shelf/README.md
  -> graphs/source-shelf.md
  -> stewardship/growth-gate.md
  -> one active file, if the reader job is real
```

Public essay theme to archive home:

```text
public /more theme
  -> one graph section
  -> one Ring 2 source shelf
  -> one active file
  -> one return outside the archive
```

## Source Migration Rule

If an outside essay,
older source file,
or public theme reveals missing source pressure,
do not paste the essay into this archive.

The public `/more` essay is an alignment check:
its major public themes should have archive homes,
but the page itself should remain outside the archive package.

First ask whether Ring 2 already preserves the pressure.
If it does not,
send the topic through [stewardship/growth-gate.md](stewardship/growth-gate.md)
before summarizing any older working source into Ring 2.

Older working source stays outside this two-ring taxonomy.

The second ring should preserve the source pressure.
The active ring should carry the route.

## Second-Brain Boundary

The archive can be mapped,
but it should not behave like a private encyclopedia of self.

Do not use the map to:

- keep opening files after the next action is clear
- turn source-shelf pressure into active doctrine
- collect concepts because they are interesting
- make a canon spine,
  glossary,
  dashboard,
  spreadsheet,
  or dumping ground
- treat the archive as authority for live empirical claims
- replace qualified human review in high-stakes situations
- let the map feel more real than the person,
  record,
  source,
  room,
  task,
  refusal,
  repair,
  or consequence

Use the map to return attention,
not to capture it.
