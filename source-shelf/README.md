# Source Shelf

This folder contains selected excerpts
and syntheses from source material.

It exists to show the pressure behind the method.
Source pressure means language,
questions,
and vocabulary that shaped the current method.
It explains why a method exists without becoming current instruction.

It is not an active route.
It is not current doctrine.
It is not required reading.

This folder is Ring 2: the source shelf.
It is part of the current two-ring archive structure:
Ring 1 is the active workbench,
and Ring 2 is the source shelf.

Keep the image plain:
Ring 1 is the table where the current tool is used,
and Ring 2 is the labeled shelf beside it,
holding source notes so a reader can lift one down without mistaking it for
the current route.

Current practice remains in the root active archive:
`GUIDE.html`, `README.md`, `LICENSE.md`, `FIELD_STANDARD.md`, `ROUTES.md`, `GRAPH.md`,
`HANDBOOK.md`, `REPORT.md`, `report.pdf`,
`methods/`, `practice/`, and `stewardship/`.

These files preserve quotable perception material from the source record
without turning source shelf files into current guidance.

Source pressure is not status pressure.
Do not use this shelf to crown an author,
archive,
metaphor,
method,
or solitary achievement.
The shelf gives handles for inquiry:
ask why,
test the source,
return to current practice,
and let the reader,
group,
or public do the work.

## Why These Are Selected

The source shelf does not reproduce every source record
or working conversation.

It preserves the pressure,
vocabulary,
and questions that changed the method,
while leaving out repetition,
scaffolding,
drift,
and material that would make a reader rebuild the whole jungle before acting.

This is not concealment.
It is a scale choice.
A shelf tag is enough here:
title,
source pressure,
and return path,
not a second cabinet dragged into the room.

The shelf gives a rough map to follow,
not the full trail of the work.

When truth is involved,
files can overgrow.
A reader should not inherit someone else's maze as proof.
The shelf gives enough source pressure to ask why,
test the claim,
and rebuild context through their own contact with evidence,
record,
body,
consequence,
and return.
