This collection extends the archive first published on October 4, 2026.

**Intentional Images** connects the image-literacy frameworks with design checks, worked examples, and a revision worksheet, giving readers practical ways to direct images, evaluate results, and preserve their intentions through revision.

**Intentional Inquiry** is a study companion to the original seven-page report, *Five Steps for Better AI Inquiry*. It provides exercises for examining claims, checking evidence, reflecting on decisions, and applying the report to everyday situations. The worksheet is available as a PDF and an editable Markdown file.

The original release remains available as the foundation. This update develops its application through additional review and teaching material.
