## What This Map Is

This is the graph for active use.

It maps the files a reader should actually use when they need a route,
method,
practice,
boundary,
or next action.

Ring 2 pressure belongs in `graphs/source-shelf.md`
and the topic maps.

## Active Ring

```text
GUIDE.html (optional)
  -> README.md
```

## File Roles

`GUIDE.html` is the browser welcome mat and short guided route through the archive.

`README.md` is the public doorway.

`FIELD_STANDARD.md` is the shortest portable discipline:
claim handling,
verification,
refusal,
repair,
and return.

`ROUTES.md` chooses one next file after the entrance.

`GRAPH.md` chooses one graph section when relationships matter before routing.

`HANDBOOK.md` is the carryable public version.

`REPORT.md` is the editable seven-page report and `report.pdf` is its generated reading copy.

`LICENSE.md` is the reuse and stewardship frame.

`methods/inquiry.md` improves the question before accepting an answer.

`methods/truth-and-claims.md` separates claim,
evidence,
inference,
uncertainty,
risk,
and action.

`methods/calibration.md` checks smoothness,
flattery,
overconfidence,
vagueness,
missing evidence,
and authority.

`methods/ai-contact.md` returns AI,
screens,
money,
dashboards,
prices,
balances,
and other abstractions to lived reality.

`practice/cards.md` turns archive pressure into short drills.

`practice/attention-hygiene.md` returns screen-assisted thought to body,
record,
consequence,
commons,
and capacity.

`practice/gathering-anchors.md` gives a room or gathering a shared subject,
light role,
and return path without forced performance.

`practice/local-loop.md` returns digital or AI-assisted creative work to people,
place,
witness,
fair exchange,
records,
and repair.

`practice/work-and-automation.md` audits AI,
productivity,
labor,
burden reduction,
automated decisions,
tools,
and agents.

`stewardship/operating-discipline.md` holds privacy,
harm,
high-stakes,
agents,
external action,
claim-status,
and nondelegable human responsibility.

`stewardship/concept-register.md` holds concepts that matter but should not become active files too early.

`stewardship/growth-gate.md` decides whether a concept,
route,
method,
practice,
or source pressure deserves promotion.

## Active Paths

Inquiry:

```text
ROUTES.md
  -> methods/inquiry.md
  -> methods/truth-and-claims.md, if a claim appears
  -> one outside question or source
```

Truth:

```text
ROUTES.md
  -> methods/truth-and-claims.md
  -> methods/calibration.md, if AI fluency is involved
  -> one source trail or correction need
```

Contact:

```text
ROUTES.md
  -> methods/ai-contact.md
  -> practice/cards.md
  -> one return through Body, Record, Consequence, Commons, or Capacity
```

Attention:

```text
ROUTES.md
  -> practice/attention-hygiene.md
  -> practice/cards.md
  -> one non-screen return
```

Gathering:

```text
ROUTES.md
  -> practice/gathering-anchors.md
  -> practice/attention-hygiene.md, if a shared screen is involved
  -> practice/local-loop.md, if making, repair, or exchange needs a repeatable local return
  -> one clear entry, role, and return
```

Local:

```text
ROUTES.md
  -> practice/local-loop.md
  -> methods/ai-contact.md
  -> one record, witness, consent, price, or repair path
```

Work:

```text
ROUTES.md
  -> practice/work-and-automation.md
  -> stewardship/operating-discipline.md
  -> owner, permission, record, review, rollback, and repair
```

Growth:

```text
stewardship/concept-register.md
  -> stewardship/growth-gate.md
  -> one active file, only if the reader job is real
```
