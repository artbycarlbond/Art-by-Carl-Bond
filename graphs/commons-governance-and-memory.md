## Public Memory Standard

Public memory needs:

- provenance
- claim status
- version memory
- correction path
- distributed copies where practical
- platform independence
- privacy boundary
- slow shelf for unresolved claims

A named case,
person,
company,
platform,
product,
controversy,
book,
meme,
slogan,
or public event should stay only when it does real work:
legal provenance,
release history,
source trail,
canon reference,
or dated memory anchor.

Prefer the portable pattern over the famous instance.

## Stops

Stop when:

- access,
  responsibility,
  refusal,
  and repair are findable
- the memory anchor has provenance and claim status
- privacy boundaries are clear
- a public room has a maintenance path
- the topic belongs in active practice,
  Ring 2 source shelf,
  concept register,
  or nowhere

## Do Not Turn This Into

- a civic platform
- public oath inflation
- governance theater
- a news archive
- a dossier
- a demand that local life solve structural failures alone
