## Creation Loop

```text
conversation
  -> creation
  -> process note
  -> image or object
  -> witness
  -> revision
  -> record
  -> fair exchange
  -> repair
  -> local memory
```

The loop should leave:

- a findable maker or chosen attribution
- a clear process note where useful
- a material standard for prints or display
- consent limits
- rights and reproduction limits
- price stack where money moves
- tax or rule verification when required
- return,
  refund,
  correction,
  incident,
  or takedown path

## Stops

Stop when one of these is clear:

- the work needs only a private draft
- the work needs a local witness path
- the image or caption needs claim checking
- rights or consent are unresolved
- money,
  taxes,
  public display,
  minors,
  privacy,
  or safety require `stewardship/operating-discipline.md`
- the framework is becoming costume instead of helping the work return

## Do Not Turn This Into

- a business plan
- a mandate to sell art
- an anti-AI doctrine
- a prompt-framework shrine
- an art-market theory
- tax,
  legal,
  or employment advice
- a demand that every creative act become public
